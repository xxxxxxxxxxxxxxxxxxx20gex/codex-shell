# 办公模板

用户明确要保存可复用模板时使用；一次性仿照参考文件直接交给对应办公 Skill。此处生成普通 CS 个人 Skill，不声称支持官方模板图库或模板卡片。

## 创建

1. 明确一个本地参考文件和用途；批量任务逐一处理。保留参考原件，不改写它。在线文件必须先由用户提供本地副本，或通过实际可用且已授权的连接器获取。
2. 按 [本地运行与渲染](../../references/local-runtime.md) 渲染参考，选第一页具有代表性的 PNG 并查看。不能渲染时说明依赖缺失，不用伪造截图替代预览。
3. 总结应保留的纸张/页面、字体、标题、颜色、表格、图表、公式和固定内容，以及哪些位置应替换。避免把样例事实变成未来任务的默认事实。
4. 使用本插件 scripts/create_template.py 创建模板，传 --reference、--preview、--name（小写字母数字和连字符）、--display-name 和 --description。命令参数按当前 Shell 单独引用。可用 --instructions-file 传入 UTF-8 的具体模板约束。
5. 脚本只写入当前 CODEX_HOME/skills；未设置时停止，不回退到官方 .codex。已有同名模板拒绝覆盖，可选择新的名称。
6. 检查生成的 SKILL.md、agents/openai.yaml、assets/reference.*、assets/preview.png；读取指令确认约束与参考一致。用户可在个人 Skills 中发现它，必要时新建对话。

## 使用与更新

使用模板时先复制参考文件到任务输出目录，再按对应办公 Skill 编辑和验证；不得编辑保留的参考原件。PDF 仅作视觉与内容参考，不能承诺像 DOCX/PPTX 一样可编辑。

更新已有模板必须定位用户指定的个人 Skill，先备份，按需更新约束或参考与预览。不要修改插件缓存，也不要自动更新同名模板。交付说明模板名称、绝对路径和调用方法；不生成官方 codex:// 插件链接或模板图库指引。
