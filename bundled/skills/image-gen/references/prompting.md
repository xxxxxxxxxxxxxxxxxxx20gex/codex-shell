# 中文提示词指南

## 推荐结构

复杂请求用短的带标签段落，顺序如下：

```text
使用场景：电商主图 / 生活方式照片 / 海报
主要目标：要生成什么
输入图片：图1是姿势构图参考（可选）
场景背景：地点、空间、时间、环境
主体：人物/商品、数量、年龄段或关键外观
画面细节：服装、道具、材质、动作、表情
构图：景别、视角、主体位置、是否全身、横竖构图
光线氛围：光源方向、软硬、色温、情绪
材质质感：皮肤、织物、金属、玻璃、木材等真实细节
约束：必须保留和必须改变的内容
避免：文字、水印、畸形手脚、动漫线稿、塑料皮肤等
```

## 写法原则

- 用户已经具体描述时只做整理，不擅自添加人物、道具、品牌、标语或故事。
- 用户描述很泛时，只补充能改善结果的构图、光线和材质细节。
- 真人摄影要直接写 photorealistic 或“真实摄影”，并补充自然皮肤纹理、真实比例、相机视角等可观察特征；不要只写“高级、逼真”。
- 人物要说明景别、身体是否完整可见、视线、动作和与物体的关系；不要随意指定左右位置。
- 参考图要说明用途。只借鉴姿势或风格时，写“仅作姿势/构图参考”，不要要求复制草图线条。
- 图片中有精确文字时，用引号给出原文，并要求逐字渲染、位置和字体；没有文字时明确“无文字”。
- 约束要具体：例如“图1用于瓶身外观参考，背景为浅灰摄影棚；准确遵循瓶身比例和标签布局”。迭代时重复关键要求，但不承诺像素级一致。
- 一次迭代只改一个问题，例如只改脸部真人感或只改背景，便于判断原因。
- 多张不同图片需要不同提示词和不同调用；不要用一次请求的数量参数代替不同任务。

## 按用途的起点

- 真人自然照片：生活方式场景、真实皮肤和织物纹理、自然光、相机镜头语言、不过度磨皮。
- 商品图：单一主体、清晰轮廓、材质和标签可读、受控光线、无无关道具。
- 草图转真人：保留布局、比例和透视，把线条转换为真实人体、家具和光影，不保留线稿。
- 电商广告：先写受众和用途，再写主体、卖点和准确图内文字；不要编造资质或功效。

## 版式、留白和准确文字

只有页面确实需要标题或按钮覆盖时才要求对应留白，不默认把主体压到某一侧。说明画面实际用途和裁切范围，重要元素不要紧贴边缘。
逐字引用标题、标签和数字，说明层级、字号相对关系、颜色、位置和“只出现一次”。罕见英文词或编号可补充分字符拼写。
生成后放大检查错字、多字、漏字、数字和单位。数据图必须使用用户提供的数据；图表、技术图若要求精确或可编辑，应使用对应绘图工具，不将位图伪称可编辑成果。

## 参考图与连续创作

图1用于外观时明确要遵循的比例、材质和颜色；用于构图时只约束布局；用于风格时指出色调、笔触和纹理。
草图转成图说明布局、比例、透视和真实材质，不无故增加新元素。抽象或矛盾的草图以自然人体、家具结构为约束，如实说明无法完全对应的位置。
连续角色或商品系列可使用已选图作为单参考图，重复关键外观描述，并逐张检查漂移。不要承诺人物身份或商品像素完全一致。
多图概念上可按“图1外观、图2风格”描述，但当前渠道多图尚未实测，不作为默认做法。

## 更多类型的提示重点

| 类型 | 需要写清楚的内容 |
| --- | --- |
| UI概念图 | 低保真还是成品视觉、设备方向、区块顺序、层级和实际控件；不是可运行界面 |
| 信息图 | 读者、阅读方向、标签原文、箭头关系、清晰留白 |
| 科学教学图 | 学习目标、必要标签、科学约束；检查关系是否正确 |
| 商务配图 | 幻灯片或图表用途、真实数据、视觉层级和可读字号 |
| 品牌概念 | 简洁轮廓、负空间、缩小后的辨识度；输出仍为位图 |
| 叙事插画 | 分格数量、每格明确动作、角色和场景连续性 |
| 风格概念图 | 绘画/三维/黏土等媒介、材质和光线，避免擅自添故事 |
| 历史场景 | 地点年代、服饰与道具依据，避免时代错置 |

## 提示词与执行参数分开

“画面背景”描述环境，不等同于API的透明背景参数。用途、风格和构图等标签只是提示词结构，不会创建新的CLI参数。
个人源文件关于内置工具、透明输出和局部处理的流程不适用于当前工作流；这里仅同步生成与参考图创作的方法。示例见 [中文模板](sample-prompts.md)。
