# 配置与凭证的来源和索引

- 先核对项目实际加载机制。`.env` 和 `config.yaml` 都是可选运行配置：简单键值及环境注入适合 `.env`，分组、嵌套、列表等结构化参数适合 `config.yaml`；已有 JSON、容器 secrets 或密钥管理服务时沿用。受限的 `config.yaml` 也可承载服务端密钥，不强制改成 `.env`；含秘密的实际配置不提交，纯非秘密配置可按项目约定纳入版本管理。两种格式仅在职责明确时共存，例如 YAML 保存非秘密参数、环境变量注入密钥，不重复维护同一值；文件名本身不提供加密或访问保护。
- 每项运行配置明确唯一权威来源、变量名、必填性、默认值、单位、读取入口和生效方式。若支持环境变量覆盖文件，明确优先级；入口集中解析并校验，业务模块接收所需配置，避免到处直接读环境变量。缺失密钥或非法配置应清晰报错，不用示例值或旧凭证静默回退。
- `.env` 不会因文件存在就自动生效：核对框架加载器、启动命令及部署注入。Docker Compose 的 `.env` 插值不等于容器环境注入，需检查 `environment`、`env_file` 或挂载。文档说明实际使用的入口及重启/热加载要求，不把计划配置写成已加载。
- 将秘密、部署参数和业务常量分开：密钥、令牌只在服务端受限来源读取；地址、模型默认值、可调整的超时与容量由配置管理；稳定业务规则和协议常量在所属模块命名并复用，标明单位。不把所有数字搬入 `.env`，不机械提取普通局部字面量，不建立包揽所有模块的全局常量文件。
- 使用 `.env` 时提供与真实读取字段一致的 `.env.example`；使用 `config.yaml` 时按需提供 `config.example.yaml`，已有不含秘密且可直接使用的版本化配置不必再复制示例。YAML 中的环境变量占位符只有加载器明确支持才会展开，不能假定 `${VAR}` 自动生效。其他格式按需提供对应示例。示例仅含占位符或安全默认值，标明必要字段、用途和单位，不含真实秘密；未配置不启用的功能不虚构参数。已有schema或配置说明能承担字段解释时不再重复维护。
- `凭证.local.md` 是按需的人工作业记录，不作为程序默认解析的配置文件，也不默认复制 `.env` 中的秘密。账号登录资料、私钥路径等按项目既有凭证方案保存，私钥保留原文件。用户或上级规范明确要求额外登记真实凭证时遵从，并在变更时同步该受限记录；程序仍只读取约定的运行来源。
- 普通文档和 AGENTS.md 只记录配置位置、加载约定、维护责任与必要索引，不写真实值。不为文档整理扫描或获取全部秘密；仅处理授权任务需要的内容，未提供或未创建的值不编造。
- 含秘密的文件限制为运行账号及必要管理员访问，并排除 Git、构建上下文和公开静态资源；示例文件可提交。前端构建变量通常会进入浏览器产物，不能放密钥。修改排除规则后检查文件是否已被跟踪；忽略规则不能清除既有提交历史。错误、日志、回复及验证输出脱敏，不打印完整配置或密钥。
- 此 skill 默认只维护上述约定与现状；迁移运行配置、修改加载代码或重启服务须在用户授权的开发范围内进行。已授权迁移时检查调用方、保留恢复路径，并验证真实加载及缺失/非法配置路径；只创建配置文件或示例不算接入完成。

## 按索引精确读取

实际值保存在程序实际使用的配置或凭证来源；普通文档只记录定位信息，不复制值。不以整理文档为由迁移秘密、创建全量凭证副本或修改加载器。

- 在现有配置说明中按用途记录：环境、所在机器或服务、来源路径或 secret 标识、字段名/键路径、读取入口、覆盖优先级和生效方式。按实际需要填写，不为无关字段建立空表。AGENTS.md 只索引这份说明，不再维护第二份字段清单。
- 简单键值可用 `.env`；嵌套账号、多供应商配置适合既有 JSON/YAML；自动轮换的令牌沿用认证服务的受限状态库；SSH 私钥和证书保留原文件。不要把这些内容全部转存到 `.env`。
- 区分磁盘配置、部署注入和进程已加载值。文件已修改不代表运行值已生效；环境变量覆盖时，索引指向实际的注入来源，不能只指向被覆盖的文件。
- 自动刷新凭证明确唯一写入者及消费者的重载方式，避免人工文档中的旧令牌覆盖新值。备份和受控部署副本不是第二个编辑来源；注明同步方向，避免两端分别维护。
- 智能体先按用途和环境定位，再由本地解析器读取指定字段，直接交给获授权的调用；只返回存在性、必要状态或脱敏结果，不把整份配置送入上下文。遵循项目解析器语义，不通过执行或 source 文件来获取值。
- 使用未定义字段、缺失配置或含糊的环境映射时，报告具体缺口；不自动从其他环境或过期凭证文档回退。

示例仅说明索引粒度，不是固定模板或已存在路径：

| 用途 | 环境/位置 | 权威来源与字段 | 消费/生效 |
| --- | --- | --- | --- |
| 供应商 API 认证 | 测试服务器 | 项目 `.env` / `SUPPLIER_API_KEY` | 后端配置加载器；重启读取 |
| 请求超时 | 测试服务器 | 项目 `config.yaml` / `http.timeout_seconds` | 后端配置加载器；单位秒 |
| OAuth 会话 | 指定认证服务 | 受限状态库 / 账号记录标识 | 认证服务轮换写入；消费者按既有机制重载 |

不为查询方便另建通用凭证系统或冗余索引格式；现有 schema、示例配置和部署说明足够定位时直接沿用。
