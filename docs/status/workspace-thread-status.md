# 项目目录与线程状态

- 图片预览：项目文件中的图片可点击打开共享批注窗口，插入到主会话草稿时自动附加原图；图片窗口打开期间 Escape 不关闭底层文件浏览器。读取失败时显示错误且不提供批注入口。回填会恢复对话可见布局，不提交消息。
- 文件定位：所有专用资源管理器入口在 Rust 边界复用 Tauri Opener 原生 Shell 定位，打开文件所在目录并选中文件；目录直接打开。删除手工拼接 Explorer `/select` 参数及标准库 canonicalize，避免参数二次转义与 Windows verbatim 路径兼容问题。只接受已存在的绝对文件或目录路径。
- 文件树菜单：右键或 Shift+F10 打开目标菜单，支持预览、图片批注、添加到当前草稿、资源管理器定位和完整路径/项目相对路径/文件名复制；文件夹支持展开折叠及打开目录。二进制文件不显示预览操作，HTML 沿用文本预览。附件复用拖入路径入口，保留正文并去重，不自动发送。菜单支持方向键、Home/End、Escape、外部点击和窗口边缘避让；操作失败显示错误。
- 当前文件：文件树以选中背景和左侧 2px 动作色标记当前预览文件；从回复链接打开嵌套文件时展开父目录并滚动到可见位置，Windows 路径分隔符及大小写差异不影响高亮。项目外文件仍只显示预览，不伪造项目树节点。

- 模块职责：管理项目目录（Thread `cwd`）、线程列表、创建、恢复与切换。
- 当前状态：新 Thread 使用发送首条消息前选择的自定义项目，未选择时使用 `Documents/Codex-Shell/YYYY-MM-DD` 默认项目目录；自定义选择不跨新对话持久化。已有 Thread 始终使用服务端返回的不可变 `cwd`，文件浏览、文件附件和相对路径解析均以该目录为根。每个非运行中的历史 Turn 都可通过原生 `thread/fork(lastTurnId, excludeTurns: true)` 从该轮末尾创建分支，再分页读取最近 200 轮；右侧侧边聊天从当前已完成 Turn 以 `excludeTurns: true` fork 一个 `ephemeral`、只读沙箱 Thread，不进入历史列表，主会话切换或关闭侧聊时退订并清理。
- 历史列表交互：行高固定 56px，闲置标题使用整行宽度，hover／焦点／菜单打开时为操作按钮让位；未归档行提供置顶／归档，归档行提供恢复。复制引用、重命名、永久删除复用共享菜单，支持右键与 Shift+F10，保持运行状态下删除／归档禁用。
- 历史手动排序：标题区域使用 Pointer Events 拖动，避免 Windows Tauri 原生文件拖入与 HTML 拖拽冲突；提供插入线、边缘滚动、Escape／失焦取消、Alt+上下键及右键上移／下移／重置。置顶和非置顶不能跨组拖动，运行中会话允许排序，归档／加载／操作锁期间禁止。只调整单条会话显示位置，分叉关系不改写；手动顺序优先于默认分支相邻排序。仅保存会话 ID，按规范化 CODEX_HOME 隔离在 WebView localStorage，最多 10,000 条；写入失败保留原序并显示错误，上限可通过重置清理。分页、归档暂时不可见的 ID 不因缺席被删除；新增会话与未排序旧页保持默认位置。历史仍由 Core 按活跃时间分页，较旧会话需要加载后才参与展示；排序不使未加载会话提前出现在首屏，不跨设备同步。Core `thread/section/move` 的 `beforeThreadId` 不支持无分组会话，因此此展示偏好不改写 Core 分组或自行写数据库。
- 标题与项目同步：会话标题优先使用 Core 名称，预览回退通过 Markdown 解析提取纯文本、合并空白，空内容显示“未命名会话”。列表与顶部统一按最多 60 个 Unicode 字素显示，完整名称保留在悬停提示和重命名输入；不截断写回 Core，不调用模型自动命名。历史列表请求期间收到的名称更新会合并到响应，防止旧快照覆盖改名；项目变更事件通过 `thread/read` 同步权威 cwd；图片/PDF 预览超过 20 MiB 时只显示超限提示。
- 宿主说明：新建主会话、独立侧聊及侧聊分叉通过原生 `developerInstructions` 注入统一 CS 宿主说明，再拼接用户自定义提示词；不覆盖 Core 基础提示词或修改系统 Skill。
- 指令生命周期：恢复历史会话不重写原有 developer instructions，普通历史分叉沿用父会话指令。因此更新前的旧会话及其普通分叉不会自动补入宿主说明，需新建对话使用。个性化仍只在创建主会话或侧聊时读取。
- 最近变更：2026-10-20，历史列表加入本机持久化拖动排序、键盘替代与重置，不改动 Core 会话内容、置顶与归档语义。
- 侧聊生命周期：侧聊订阅由侧聊生命周期独占管理，完成一轮后保持订阅，不再被主会话的后台清理误退订。创建、发送通过代际校验隔离主会话切换、关闭、Runtime 重置及卸载后的迟到响应；关闭立即清空本地状态，再清理旧线程，不覆盖重新打开的侧聊。迟到创建释放订阅，迟到发送先中断再释放。异步问题卡片可回答：运行中使用原生 `turn/steer`，空闲时使用原生 `turn/start`；输入法组合期间 Enter 不发送。
- 分叉与回退：侧聊分页分叉显式排除响应中的父历史（模型仍继承上下文）；普通分叉只分页读取最近 200 轮。消息回退复用 Core 返回的 metadata／cursor，本地主动回退与 `thread/reverted` 不再重复加载，切换、重置或新 Turn 使旧刷新结果失效。回退已提交但历史刷新失败时清除旧编辑目标并保留草稿，重发不会再次回退。
- 侧聊提交边界：完成通知通过同步 Turn ID 标记防止迟到的 `turn/start` 响应覆盖终态或重新登记运行；提交锁只由请求收尾或生命周期重置解除，不由 Turn 通知提前解除。成功只清除未被重新编辑的草稿版本，失败保留草稿。移除无消费者的 `open` 状态，分叉目标只计算一次。
- 队列与历史：队列执行统一由 `thread/queue/*` 管理，删除本地自动发送及伪 Runtime 能力检测分支。提交中消息保留在界面，撤回等待入队 ID 和 Core 的 `deleted: true`；失败保留服务端队列状态，已开始执行时明确报错。撤回期间禁止切换会话，编辑／引导在撤回成功后继续；引导失败回填草稿。通知刷新合并并保留未确认操作，Runtime reset／卸载使在途结果失效。旧 legacy 历史的原生读取／恢复仍保留，不能假定后台迁移已完成；迁移边界见 [协议状态](protocol-status.md)。
- 当前接口：Rust `get_default_project_directory`，以及 `WorkspaceSelector`、`WorkspaceExplorer`、`ThreadHistoryList`、`ConversationTimeline`、`useWorkspaceFiles`、`useThreadController` 和 `useThreadActions`。时间线滚动控制以当前可见用户消息为锚点，在上一条、下一条和最新位置之间跳转。
- 交互校正：右侧功能区中的“项目文件”入口在存在项目路径时直接打开 `WorkspaceExplorer`；无路径时仅显示准备提示，避免重复的二级打开按钮。
- 文件预览边界：图片和 PDF 超过 20 MiB 时不创建前端 Data URL，只显示超限提示；文件内容仍由 app-server 的 `fs/readFile` 返回后才可判断大小，尚未实现源端按字节分页读取。
- 已知问题：尚未提供显式的最近项目列表；侧边聊天暂不支持审批、队列或写入操作；继续扩展 Thread 通知路由前仍应优先按生命周期职责拆分。
