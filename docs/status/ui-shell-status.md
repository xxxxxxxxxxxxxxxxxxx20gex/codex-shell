# 桌面 UI 壳状态

- 模块职责：提供 Windows 桌面三栏智能体工作台和响应式布局。
- 当前状态：P0 三栏工作台已接入完整执行时间线、统一服务端交互、Diff、原生 Review、模型目录、多 Session 并行和工作区实时刷新。
- 最近变更：对话区进一步对齐 Codex 桌面端的连续流：正文和输入采用官方桌面端的 16px 对话尺度，过程说明为 14px，活动标题为 12–13px，时间等辅助信息为 11px；执行过程可逐项折叠，最终回答支持安全 Markdown。输入框在运行中保持可编辑，但只有 app-server 已确认的普通 Turn 才显示“执行中 · Enter 插入”并开放发送，Review、手动压缩、仅从历史恢复的 active Turn 以及等待批准/输入阶段改为准确状态且禁止误提交。原右侧散点消息导航改为左侧窄轨道，通过灰色刻度表达历史用户 Turn、亮色长刻度表达当前阅读位置，悬停显示摘要、点击跳转且不显示动态编号。对话标题使用固定 24px 安全边距，不再随正文宽屏留白增长到 90px；消息时间与气泡/回答正文保持 8px 垂直留白，避免时间戳贴边。右侧功能区默认收起，左侧 Session/工作区栏默认展开；分隔线按钮可恢复右栏。权限入口默认“完全访问权限”。Session 历史保留路径/ID 复制，分叉与复制回答位于当前已完成回答底部。模型、权限和命令弹层支持外部点击、Escape 关闭及焦点返回；模型和推理参数变化保持当前 Session。
- 当前接口：`App`、三栏布局、`StatusInspector`、Runtime Log/Notice、`ServerInteractionDialog`、工作区浏览器、slash/Skill/MCP/Goal/Review 面板、时间线、Diff 和模型设置。
- 已知问题：文件搜索和会话操作尚未完成全键盘导航；移动宽度仍隐藏侧栏与检查器；`App.css` 仍集中承载多个 feature 的样式，后续应随功能改动逐块迁移，避免继续扩大共享样式耦合。
- 下一步：补齐拖拽分隔线的键盘宽度调节、文件/会话键盘导航和无障碍状态播报。
- 验证证据：布局 Hook 测试覆盖左栏展开、右栏收起及 CSS 宽度变量；Sandbox 状态卡 DOM 测试覆盖按钮向 app-server 传递 `elevated`；ConversationTimeline 测试覆盖执行过程归并、原始活动顺序、安全 Markdown、助手短竖线、无头像/名称、回答复制与分叉按钮；运行状态测试覆盖普通可插入 Turn、Review、Compact、未知 active 与等待标志；ThreadHistoryList 测试确认历史列表不显示分叉入口。完整门禁结果记录于测试状态文档。
