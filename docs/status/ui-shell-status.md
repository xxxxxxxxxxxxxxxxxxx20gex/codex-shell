# 桌面 UI 壳状态

- 模块职责：提供 Windows 三栏工作台、设置面板、主题与系统窗口交互；视觉契约以 [DESIGN.md](../../DESIGN.md) 为准。
- 当前状态：左栏管理 Session，中间承载对话或技能管理页，右栏提供项目文件和只读侧边聊天。Inspector 主页与侧聊默认 288px，项目文件视图默认 400px、文件树默认 220px；支持拖拽调整。主要区域头部统一 48px，文件预览路径条为 32px，头部操作使用 28px `CompactIconButton`。
- 最近变更：2026-10-23，修复运行窗口任务栏显示空白文件图标。Tao 默认只设置 `ICON_SMALL`；主窗口显示前从 EXE 的 Tauri ICO 资源按启动时默认大图标尺寸加载并设置 `ICON_BIG`，共享资源句柄随模块存活。真实 Windows Debug 窗口检查和任务栏截图已确认显示批准的 C 版图标。
- 主题与控件：源码／Debug 已采用 Soft Notebook，浅色为纸白奶油底、淡紫选中和浅黄主动作，深色为中性黑灰、灰色选中和浅灰主动作；新配置默认浅色，已有偏好保留。主界面与右键 Portal 共用主题并实时跟随系统。新建对话使用中性抬升底色与主文字，hover／键盘聚焦使用选中底色；设置、渠道、技能和命令菜单减少框线。公开 v0.1.13 安装器尚未包含这些开发版视觉更新。
- 品牌资源：批准的 C 版为淡紫圆角底与紫色对称代码符号，标题栏引用 PNG 母版，平台图标由 Tauri icon 派生；不得恢复旧 CS 字母图标或重新描画批准符号。任务栏修复未清理系统缓存，也未修改固定快捷方式。
- 空会话插画：两个参考小狗使用提取轮廓的 SVG，保持长耳、红项圈、抱爪、短胖比例和白狗的手绘毛边及有意线条断口。以 162px 宽等比展示，两只狗独立小幅起伏／轻摆，草叶连续后移，统一 1.6 秒周期。按用户要求在 reduced-motion 下仍播放；无额外运行库、JavaScript 计时器或音频，未实现原视频逐帧抬爪。
- 默认窗口：启动最大化；标题栏还原按钮和双击共用 `toggle_window_maximized`，按当前显示器工作区宽、高的 85% 居中。最小外框为 900×640 逻辑像素，换算 DPI 并受工作区上限约束。普通窗口跨显示器、DPI 或工作区变化时只校正不再适配的边界，最大化／最小化时暂缓；不保存退出位置和大小。原生拖拽／快捷键还原沿用 Windows 保存位置。自绘标题栏不保证 Windows 11 Snap Layout 悬停菜单。
- 设置：保留个性化、外观、模型渠道、运行环境、诊断五类；仅关闭窗口操作，无最大化模式。渠道编辑替换列表；切换分类或关闭设置会丢弃未保存的渠道草稿。模型与凭据事务见 [模型配置](model-config-status.md)。
- 输入区：目标和队列为 Composer 上方独立无框行；提示关闭、目标清除、队列操作复用紧凑图标按钮。Composer 右上手柄向上拖动增高，范围 64–320px，支持方向键和 Escape；编辑历史消息直接显示原文。叠放布局和导航避让见 [时间线](timeline-status.md)，队列及提交生命周期见 [项目与线程](workspace-thread-status.md)。
- 发送动作：发送／停止统一 32px 点击区域、共享 12px 面板圆角与居中 16px 图标。发送使用向上箭头和主题主动作色；禁用时为弱化底色。停止默认中性，hover／键盘焦点显示危险色。排队、引导与停止回调保持既有语义。
- 菜单与交互：添加、权限、历史和右键菜单共用几何与焦点样式；不能据此宣称所有菜单已具备同样的键盘导航。标准模态框、确认框、附件预览和服务端交互遮罩消费共享 Token；Skills 原生 dialog backdrop 仍使用局部颜色混合。历史标题闲置时使用可用宽度，hover／聚焦／菜单打开时为操作让位，完整历史交互由项目与线程状态维护。
- 右键策略：只覆盖应用 DOM，不接管 iframe 文档查看器；编辑区提供选择／复制／粘贴，选中正文提供复制，文件树使用专用菜单。带本地路径的回复链接、资源和文件变更支持复制绝对路径，相对路径基于会话项目解析。粘贴在点击时读取剪贴板，拒绝时提示 Ctrl+V，不覆盖草稿；复制降级临时文本框通过 finally 释放并恢复焦点。
- 提示规则：普通信息／弃用提示 5 秒，一般警告 8 秒，安全提示持续到关闭或解除；普通重复提示刷新计时，MCP 同一可见启动失败不延长计时。沙箱准备完成清理旧提示，设置入口使用管理员模式。MCP 启动提示与模型安全缓冲的具体生命周期分别由 [扩展能力](agent-capabilities-status.md) 和 [客户端](app-server-client-status.md) 维护。
- 草图：共享图片预览支持本地图片编辑和 `/绘图` 空白画布，纯黑工作面、顶部浮动工具胶囊、左侧笔触粗细轨道和底部色板。支持添加／粘贴图片、画笔、直线、矩形、橡皮擦、颜色、大小、撤销／重做；取消指针恢复绘制前状态，保留最近 30 步。保存通过 Tauri `save_pasted_image` 生成独立 PNG 并附加到草稿，不自动发送；失败显示错误。托管 `fileId` 只读；空白画布取消关闭整个窗口，从已有图片进入则返回预览。
- 当前接口：`App`、`WindowTitleBar`、`ContextMenuPolicy`、`ContextMenu`、`moveMenuFocus`、`PreferencesPanel`、`useResizablePanels`、`WorkspaceExplorer`、`SideChatPanel`、`TransientNotice`；Rust 原生窗口入口为 `window_layout` 与 Windows 专用 `window_icon`。
- 已知问题：运行中发送方式菜单由 hover／focus-within 控制，缺少 Escape 关闭和方向键导航；文件／会话完整键盘导航、分栏拖拽键盘调宽、队列与侧聊状态播报仍不完整；会话重命名使用系统 `window.prompt`。附件和提及标签的移除按钮尚未全部收敛到契约；`App.css` 的部分多规则单行及未引用 `.inspector-tab*` 待独立代码健康审查。
- 下一步：补齐上述键盘与播报边界；验收真实 WebView2 手写触控、长期动画性能和跨实体显示器行为，不将浏览器夹具结果视作完整桌面验收。
- 验证证据：2026-10-23，工作台、输入区、渠道、MCP、提问、草图、代码块与 Soft Notebook 四尺寸浏览器专项已有通过记录；Soft Notebook 覆盖技能／详情、斜杠菜单、四个设置分类、空状态、Portal、深浅主题与系统切换，模型渠道另由专用探针覆盖。检查文字下限、对比度、图标、焦点、关闭和布局边界；每个探针只证明自身覆盖的交互。小狗在两种 motion 偏好下均播放且布局稳定，独立 SVG 周期首尾截图一致。完整质量基线与命令入口见 [测试与发布](testing-release-status.md)。
- 原生专项：`check-window-icon.ps1` 在 Windows PowerShell 5／PowerShell 7 通过，任务栏大图标与 EXE 资源逐像素一致，本机 150% DPI 下为 48×48；真实任务栏截图已复核。窗口最大化／还原已有 Win32 和 WebView2 定向证据；未覆盖干净安装、固定快捷方式缓存、跨实体显示器或完整 WebView2 端到端流程。
