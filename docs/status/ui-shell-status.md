# 桌面 UI 壳状态

- 模块职责：提供 Windows 桌面三栏智能体工作台和响应式布局。
- 当前状态：P0 三栏工作台已接入完整执行时间线、统一服务端交互、Diff、原生 Review、模型目录、多 Session 并行和工作区实时刷新。
- 最近变更：对话区进一步对齐 Codex 桌面端的连续执行流：原生 commentary 作为过程正文，reasoning 作为低强调说明，命令与工具使用紧凑折叠行，文件修改保持在回答末尾；不显示外层“执行过程”卡片，也不生成 app-server 未提供的过程内容。消息轨道和运行项展开只在虚拟列表真实到达底部时恢复自动跟随，用户查看历史期间保持当前位置并显示“返回最新”。输入框在运行中保持可编辑，普通 Enter 排队，显式 `Ctrl+Shift+Enter` 才插入当前执行。
- 当前接口：`App`、三栏布局、`StatusInspector`、Runtime Log/Notice、`ServerInteractionDialog`、工作区浏览器、slash/Skill/MCP/Goal/Review 面板、时间线、Diff 和模型设置。
- 已知问题：文件搜索和会话操作尚未完成全键盘导航；移动宽度仍隐藏侧栏与检查器；`App.css` 仍集中承载多个 feature 的样式，后续应随功能改动逐块迁移，避免继续扩大共享样式耦合。
- 下一步：补齐拖拽分隔线的键盘宽度调节、文件/会话键盘导航和无障碍状态播报。
- 验证证据：布局 Hook 测试覆盖左栏展开、右栏收起及 CSS 宽度变量；运行与控制器测试覆盖普通 Enter 排队、显式 Steer、队列取消/上限、跨 Session 隔离、中断暂停和继续；ConversationTimeline 测试覆盖执行过程归并、原始活动顺序、安全 Markdown、助手短竖线、回答复制与分叉。完整门禁结果记录于测试状态文档。
