# 桌面 UI 壳状态
- 模块职责：提供 Windows 桌面三栏智能体工作台和响应式布局。
- 交互修复：已完成 Turn 在最终回答后显示本轮产出资源框；仅汇总图片、PDF 与表格文件（CSV/ODS/XLS/XLSX），图片复用缩略图/大图预览，文档提供索引与资源管理器跳转；代码等普通文件不再重复展示，仍可在文件变更折叠框中审查，且该折叠框默认收起。
- 交互修复：右侧项目文件或侧聊最大化时开始拖动分隔线会自动恢复可调宽度；分隔线与项目文件最大化按钮扩大点击热区，图标视觉尺寸保持不变。
- 当前状态：P0 三栏工作台已接入完整执行时间线、统一服务端交互、Diff、原生 Review、模型目录、多 Session 并行和项目目录实时刷新；右侧 inspector 默认显示功能入口页，项目文件浏览与 Codex 风格侧边聊天从入口进入，文件变更由会话时间线展示。时间线在离开底部后于右侧竖向提供上一个用户消息、下一个用户消息和返回最新三个图标控制，边界按钮自动禁用；对话标题栏的右侧抽屉开关固定定位，窄窗口不会被标题或 Session ID 挤出。
- 最近变更：主题敏感颜色已从根级过渡别名迁移到 canonical 语义 Token，修复浅色与跟随系统浅色模式下模型选择、会话选中、Composer 菜单、附件、Diff 和诊断状态仍继承深色值的问题；深色配色保持不变。左侧历史会话改为固定 56px 行高、标题 14px 在上、时间/运行状态 11px 在下的两层排版，上下留白对称；标题默认使用完整行宽；悬停操作区仅在当前 Session 行内显示并通过局部渐隐覆盖按钮区域，不覆盖其他会话文字，复制、重命名、删除等操作仅从右键菜单进入；标题字重使用 500，避免视觉过重。会话标题、会话标题栏、用户消息、AI 正文和过程说明明确统一使用 `--font-ui`，只有时间、Session ID、路径、命令和快捷键保留 `--font-mono`；字号层级仍按设计规范区分。左侧历史会话标题对齐 Codex 风格，时间元数据继续使用弱化的小字号；左右分隔线拖动通过 `requestAnimationFrame` 合帧并在拖动时关闭布局过渡，减少高频 pointermove 引起的重排卡顿；`imageView` 与已保存的 `imageGeneration` 过程项复用附件缩略图和大图预览，读取失败时保留路径错误提示；立即引导发送在等待 app-server 返回原生 userMessage 事件期间显示发送中提示，成功后显示处理中反馈；命令抽屉改为低对比度的单行活动条，去除外框与多余分隔线，保留悬停反馈和展开详情；右侧 inspector 改为“功能入口页 → 具体功能”的两级结构，项目文件以内嵌方式与侧边聊天共享面板生命周期，标题栏操作统一为无边框图标按钮并通过右侧栏状态控制最大化/恢复；侧边聊天只有在 ephemeral Thread 创建成功后才进入详情页，fork 继承的主会话历史仅用于模型上下文、不在右栏重复渲染；详情页由固定高度和单一内部滚动容器承载，Composer 固定为紧凑 42px 初始高度并限制最大高度；侧聊关闭时会中断活动 Turn（连接可用时）再退订，主 Session 切换或 Runtime 重置后自动返回功能入口；Composer 复用 `--font-ui` 和 `--shadow-popover` 语义 Token；侧聊支持从主 Thread 最近已完成回合 fork、独立流式时间线、最大化/恢复和 `Ctrl/Cmd+Alt+S` 打开；移除重复的右侧 Diff 面板；运行环境与诊断位于固定尺寸设置窗口；所有操作反馈横条统一由 `TransientNotice` 承载，支持右侧关闭按钮和 5 秒自动消失，错误与成功提示共享 38px 高度、间距和语义颜色；切换 Session 会清理旧提示。
- 当前接口：`App`、`WindowTitleBar`、侧栏主操作、三栏布局、四分类 `PreferencesPanel`、Runtime Log/Notice、`ServerInteractionDialog`、Tauri Opener、工作区浏览器、`SideChatPanel`、`ComposerAddMenu`、`ComposerIntentControl`、slash/Skill/MCP/Review 面板、时间线、Diff 事件消费和模型设置。
- 交互校正：项目文件入口直接打开 WorkspaceExplorer，并以内嵌方式挂载在右侧 inspector，与侧边聊天共享面板生命周期；只有默认项目路径尚未准备好时才进入提示页，不再要求用户重复点击“打开项目文件”。项目文件标题栏使用固定在右上角的无边框 28px 单一最大化/恢复切换按钮和关闭按钮，长路径不会挤出操作区，关闭后返回功能入口。左右抽屉开关移入对话标题栏两端，使用左右镜像的分栏图标；分隔线仅保留拖拽调整宽度，不再承载展开/隐藏按钮。左侧会话列表限制为纵向滚动，长标题和分支缩进不会再产生底部水平滚动条。
- 已知问题：无边框自绘最大化按钮通常不会触发 Windows 11 原生 Snap Layout 悬停菜单；文件搜索和会话操作尚未完成全键盘导航；拖拽分隔线尚未支持键盘调宽；Shell Queue、侧边聊天输入、Tauri IPC 错误与运行状态仍缺完整无障碍播报。侧边聊天当前固定为只读沙箱且不支持审批交互，适合旁聊和分析，不承担主会话的写入任务。Headless 浏览器不具备 Tauri transport，因此窗口动作以单元测试、capability 校验和桌面构建为准。
- 下一步：补齐分隔线键盘宽度调节、文件/会话键盘导航和运行状态无障碍播报；随后逐步把仍位于 `App.css` 的 Composer/时间线样式继续迁回 feature owner，但不再以末尾覆盖方式迁移。
- 验证证据：设置组件测试覆盖四个分类、elevated Sandbox 配置、诊断内容和指定分页直达；主题迁移后的完整质量门禁通过。浏览器 computed style 确认浅色 `--surface-selected=#dce4d8`、`--text-primary=#1c211d`、`--border-subtle=#d7ddd7`、`--accent-action=#628b19`，深色 Token 保持原值；1440×900、1280×780、1024×720 和 900×700 均无页面级横向溢出。
- 操作区视觉校正：Session 行采用单列流式内容，标题默认使用完整行宽，不再永久预留右侧操作安全区，避免形成贯穿列表的黑色空栏；操作区绝对定位在当前行右侧，默认使用 `display: none`，仅在当前行悬停、键盘聚焦或右键菜单打开时显示。可见操作区只包裹当前 Session 的按钮，并在按钮下方提供从左侧透明渐隐到右侧面板色的局部背景；默认列表不会绘制任何遮罩。置顶、归档仍是唯一的行内操作，复制、重命名、删除等继续通过右键菜单进入。会话行高度为 56px，标题与时间上下排列并保持稳定间距，给中文标题和分支缩进留出空间。
- 最近变更：Skills 选择面板独立提高最大高度至 460px（同时受视口 72vh 限制），减少频繁滚动；其他命令面板高度保持不变。

- 设计规则补充：修改按钮或控件前必须先核对已接受的设计稿与运行 Token，按主/次/幽灵/危险层级复用统一尺寸、间距和状态，不为单一页面另造尺寸或颜色。
- Composer Skill 标签改为 26px 紧凑行高，图标、名称和移除按钮统一对齐；使用低对比度信息色背景，避免标签撑高输入区或形成突兀的大边框。
- 消息导航的上/下/返回最新按钮移除投影，仅保留边框和主题表面色，避免在浅色模式形成按钮下方的大块阴影。
- 右侧 Inspector 最大可调宽度提升至 760px；项目文件浏览器新增文件树/预览区独立分隔线，提供 8px 拖拽热区和 210–520px 文件树宽度范围，避免只能拖动外层栏或无法调整预览区域。
- Explorer 内部分隔线拖动改用 requestAnimationFrame 合帧并在结束时刷新最后位置，避免每个 pointermove 触发同步重排；头部操作区不再继承左侧信息区的 100% 宽度规则，小窗口下最大化/关闭按钮保持在可视范围内。
- 外层 Inspector 与 Explorer 内部分隔线拖动期间改为直接更新 CSS 变量，避免每帧 React 重渲染；指针释放后再一次性同步宽度状态，保持拖动流畅与最终值一致。
