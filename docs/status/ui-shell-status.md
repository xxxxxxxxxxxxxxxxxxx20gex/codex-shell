# 桌面 UI 壳状态

- 模块职责：提供 Windows 桌面三栏智能体工作台和响应式布局。
- 当前状态：P0 三栏工作台已接入完整执行时间线、统一服务端交互、Diff、原生 Review、模型目录、多 Session 并行和工作区实时刷新。
- 最近变更：对话区进一步对齐 Codex 桌面端的连续流：每轮只保留一条轻量执行过程摘要，过程活动可逐项折叠，完成后收起；最终回答支持标题、列表、表格、引用、链接及代码块，不再直接显示 Markdown 标记。右侧功能区默认收起，左侧 Session/工作区栏默认展开；分隔线按钮可恢复右栏。权限入口默认“完全访问权限”，Windows Sandbox 设置使用管理员权限配置。Session 历史保留路径/ID 复制，分叉与复制回答位于当前已完成回答底部。历史列表依据 app-server 原生 `forkedFromId` 展示父子层级；Session 操作栏使用正常 Grid 布局，悬停或键盘聚焦时增加背景亮度、左侧强调线和轻边框光效。模型、权限和命令弹层支持外部点击、Escape 关闭及焦点返回。输入框模型入口直接选择原生模型和推理强度，高级设置管理网关、Key、自定义模型与扩展参数，参数变化保持当前 Session。
- 当前接口：`App`、三栏布局、`StatusInspector`、Runtime Log/Notice、`ServerInteractionDialog`、工作区浏览器、slash/Skill/MCP/Goal/Review 面板、时间线、Diff 和模型设置。
- 已知问题：文件搜索和会话操作尚未完成全键盘导航；移动宽度仍隐藏侧栏与检查器；`App.css` 仍集中承载多个 feature 的样式，后续应随功能改动逐块迁移，避免继续扩大共享样式耦合。
- 下一步：补齐拖拽分隔线的键盘宽度调节、文件/会话键盘导航和无障碍状态播报。
- 验证证据：布局 Hook 测试覆盖左栏展开、右栏收起及 CSS 宽度变量；Sandbox 状态卡 DOM 测试覆盖按钮向 app-server 传递 `elevated`；ConversationTimeline 测试覆盖执行过程归并、原始活动顺序、安全 Markdown、助手短竖线、无头像/名称、回答复制与分叉按钮；ThreadHistoryList 测试确认历史列表不显示分叉入口。完整门禁结果记录于测试状态文档。
