# 桌面 UI 壳状态

- 模块职责：提供 Windows 桌面三栏智能体工作台和响应式布局。
- 当前状态：P0 三栏工作台已接入完整执行时间线、统一服务端交互、Diff、原生 Review、模型目录、多 Session 并行和项目目录实时刷新。
- 最近变更：Session 操作区固定在条目右侧上层，悬停或键盘聚焦时覆盖右侧内容，不插入额外布局行；普通状态下时间贴近条目右边缘，过长名称使用省略号，操作区前使用渐隐遮罩避免按钮直接压住文字。对话区进一步对齐 Codex 桌面端的连续执行流：过程头在运行中实时显示“已处理 N 秒”，完成后使用 app-server 原生耗时；commentary 作为过程正文，reasoning 作为低强调说明，命令与工具使用默认折叠的紧凑行，文件修改保持在回答末尾；运行中悬停发送按钮可选择 Queue 或 Steer，已排队消息支持直接 Steer。
- 当前接口：`App`、三栏布局、`StatusInspector`、Runtime Log/Notice、`ServerInteractionDialog`、工作区浏览器、slash/Skill/MCP/Goal/Review 面板、时间线、Diff 和模型设置。
- 已知问题：文件搜索和会话操作尚未完成全键盘导航；移动宽度仍隐藏侧栏与检查器；`App.css` 仍集中承载多个 feature 的样式，后续应随功能改动逐块迁移，避免继续扩大共享样式耦合。
- 下一步：补齐拖拽分隔线的键盘宽度调节、文件/会话键盘导航和无障碍状态播报。
- 验证证据：Session 列表悬停布局通过固定高度和绝对定位操作区实现，时间在普通状态下使用网格末列贴右，按钮出现时仅覆盖该区域；布局 Hook 测试覆盖左栏展开、右栏收起及 CSS 宽度变量；运行与控制器测试覆盖普通 Enter 排队、显式 Steer、队列取消/上限、跨 Session 隔离、中断暂停和继续；ConversationTimeline 测试覆盖执行过程归并、原始活动顺序、安全 Markdown、助手短竖线、回答复制与分叉。完整门禁结果记录于测试状态文档。
