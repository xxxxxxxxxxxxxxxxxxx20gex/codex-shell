# 任务时间线状态

- 图片批注入口（2026-09-14）：历史用户附件、工具图片和生成图片的共享预览通过 `ImageAnnotationContext` 回填主会话草稿；原图按路径或 URL 去重附加，已有正文与 Skill 保留，不直接发送、不修改原文件。Markdown 图片可点击，本机图片进入共享预览，外部 URL 仍由浏览器打开。图片批注仅在预览会话内保存，关闭未插入的批注不会持久化。
