# 任务时间线状态

- 用户消息操作：2026-10-09，气泡下方复制／编辑按钮采用 24px 点击区域和 14px 图标，移除悬停描边，保留中性底色与键盘焦点环；助手回复操作尺寸不变。

- 表格复制：Markdown 表格右上角提供独立复制按钮，包含表头，以 TSV 文本保留行列；单元格内换行／制表符转为空格，复制格式化文字的文本值，不包含链接目标或外围回复。流式回复复制点击时的当前表格；失败可重试，反馈计时器卸载时清理。
- 表格验证：2026-10-09，3 项复制回归及既有 6 项 Markdown 测试通过，覆盖多表隔离、格式化文本、空单元格、流式更新与失败重试；四尺寸 Edge 探针验证键盘复制、焦点、尺寸与页面边界。未人工验收 Excel 或 WebView2 剪贴板权限。

- 模块职责：把用户消息、智能体消息、计划、工具、命令和错误归一化为结构化多轮时间线。
- 当前状态：消息、计划、推理、命令、文件、MCP、动态工具、搜索、图片与子智能体活动均进入连续的结构化时间线；最近 200 个 Turn 直接挂载在单一原生滚动容器中。完成 Turn 的回复资源支持本地图片预览、Markdown 文件跳转和右键复制绝对路径；活动缩略图按需读取。回复中提到的本地资源通过 app-server `fs/getMetadata` 校验存在后才展示，避免把失败生成的路径误显示为附件。
- 消息编辑：末回合结束后可替换单条用户输入，发送前使用 `thread/revert` 返回的 metadata／cursor 获取保留历史，并消费对应通知避免重复加载。会话切换、Runtime reset 或新 Turn 后忽略迟到刷新。回退失败保留编辑草稿；回退已成功但历史刷新失败则清除旧编辑目标，保留草稿供重新发送。回退不撤销文件修改，多用户输入回合不支持单条替换。
- 图片与文档：本地图片进入共享预览与批注窗口；本地 Markdown 无论是否位于项目内均进入 CS 文件面板，外部 URL 仍由浏览器打开。资源路径规范化不会放宽文件读取边界。
- 回复附件：v0.1.13 将回复中的本地图片、Markdown、PDF、表格统一到一个附件区，图片保留缩略图，其余使用紧凑文件行。过程资源默认折叠，展开只显示文件行，不读取过程缩略图、不重复标题；过程 Markdown 也保留打开入口。按规范化路径跨回复／过程去重，不推测原图与预览之间的派生关系；正文链接不变。单元测试覆盖不同路径预览保留、同路径去重、PDF／表格、文档过程资源和打开回调；四尺寸 Edge 使用模拟文件回调验证布局与操作。
- 正文资源链接：2026-10-20，Markdown 文件／网页链接统一使用蓝色，hover 下划线与键盘焦点环；本地文件带 16px 文件图标。图片语法转换为文字链接，不再让浏览器直接加载磁盘路径产生破图；本地缩略图仍由回复资源区读取。引用式图片和带外层链接的图片保留跳转目标，不产生嵌套交互元素。非法协议退为普通文字，打开失败继续通过既有提示回报。
- 代码块：Markdown 围栏代码铺满回复列，使用统一底色、12px 圆角、代码图标和语言标题；头部为 32px，语言标签 12px，复制/换行按钮仍为 28px；右上提供自动换行与复制。默认长行内部滚动，换行只影响显示，不改变复制文本。2026-10-08 四尺寸 Edge 探针及 6 项 Markdown 测试通过。
- Soft Notebook 外观：2026-10-23，提问区域改为无框提示和淡紫选择行，自由输入使用轻填充面；提交用浅黄动作，失败/锁定/回答恢复语义不变。代码块移除外描边并压低头部，标题栏用输入面 Token 与正文区分。四尺寸提问深浅主题与代码块的长行、换行、复制、键盘焦点探针通过。
- 版面：主会话内容列与 Composer 共用 760px 内容上限，左右留白取全局 gutter 与紧凑按钮高度加 `--space-3` 的较大值（当前至少 40px），保证两侧导航可见可点击；输入区外层透明且不截获空白边缘点击，仅实际子内容接收事件。回合列与输入框左右对齐，回复保留 16px 标记缩进。命令输出、过程事件与终端交互使用 13px/20px，时间线滚动按钮为 28px、16px／1.75 图标。侧聊维持原 gutter。
- 最近变更：2026-10-10，异步问答卡片独立为 `AsyncQuestionCard`，选项题也始终允许自由输入；提交时冻结答案、防止重复调用，失败保留草稿并允许重试。回答沿现有 send／steer 发送官方 `send_user_message_question_reply` 文本封装，`questionItemId` 使用工具名、消息 Item ID 和问题索引。加载历史时仅从 Core 确认的用户消息按 ID 恢复已答状态，忽略乐观输入；用户气泡显示问答正文，不展示协议标签。旧纯文本答案及未加载的历史不推断关联。
