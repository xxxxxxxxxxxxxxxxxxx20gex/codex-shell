# 任务时间线状态

- 图片批注入口：历史用户附件、工具图片和生成图片的共享预览通过 `ImageAnnotationContext` 回填主会话草稿；原图按路径或 URL 去重附加，已有正文与 Skill 保留，不直接发送、不修改原文件。Markdown 图片可点击，本机图片进入共享预览，外部 URL 仍由浏览器打开。图片批注仅在预览会话内保存，关闭未插入的批注不会持久化。

- 消息编辑：末回合结束后可替换其单条用户输入，发送前 thread/revert 回退分页历史，仅明确不支持分页时用 thread/rollback；编辑时直接复用普通 Composer 输入框，不显示编辑提示条或取消按钮；回退失败保留草稿且不撤销文件修改。多用户输入回合不支持单条替换。用户时间为 YYYY/MM/DD HH:mm，正文 14px，支持复制。
- 资源展示：完成 Turn 的回复预览只展示最终回复（历史无 phase 消息也纳入）的本地图片链接及图片引用，标题为“回复中的图片”；Markdown、PDF、表格等普通文件不再重复列出，仍可从正文链接打开。支持引用式链接，忽略代码块和外部 URL。imageView、imageGeneration 和非删除 fileChange 的视觉资源折叠保留为“过程资源”，展开后才读取缩略图；按路径分隔符和大小写去重，图片回复优先。这不是完整交付物清单，相对/绝对路径别名仍可能重复。
- 图片与文档跳转：本地图片进入共享预览与批注窗口；本地 Markdown（.md/.markdown）无论是否位于项目内均进入 CS 文件面板，以文本方式查看。项目外 Markdown 不会作为项目子目录展开，不改变当前会话项目。其他项目外普通文件沿用系统定位。资源列表的文件夹按钮明确调用资源管理器定位。
- 模块职责：把用户消息、智能体消息、计划、工具、命令和错误归一化为结构化多轮时间线。
- 当前状态：消息、计划、推理、命令、文件、MCP、动态工具、搜索、图片与子智能体活动均已进入连续的结构化多轮时间线；最近 200 个 Turn 直接挂载在单一原生滚动容器中，避免虚拟列表测量与滚动控制互相竞争。
- 最近变更：回复本地链接、回复/过程资源缩略图、附件及文件变更条目支持右键复制绝对路径；相对路径复用当前会话项目解析并规范化 `.` / `..`，Markdown 行号引用不进入剪贴板。规范化不会放宽文件读取边界；外部 URL 和未落盘图片不提供该动作，解析失败明确报错，左键打开及既有输入框/文件树菜单不变。
- 当前接口：`agentSessionReducer`、`ConversationTimeline`、`ConversationTurn`、`TurnActivityGroup`、`TurnActivityItem`、`MarkdownContent`、`TurnFileChanges`、`TurnPlanView`。
- 已知问题：MCP/动态工具的结构化结果仍以安全截断 JSON 展示；自动审批通知由 Core 标记为不稳定协议，因此 UI 只依赖最小摘要字段；尚未提供活动类型过滤。
- 下一步：增加活动筛选、单个超长命令日志的局部截断/虚拟化，补消息编辑真实 Runtime 验收。
- 验证证据：2026-09-16 至 2026-09-18，组件回归与四尺寸浏览器检查覆盖过程折叠、键盘操作、长命令、路径复制、仅图片回复预览及项目外 Markdown 文本查看；消息编辑控制器回归通过，但真实 Runtime 编辑链路及对应四视口验收未完成。完整基线见 [测试与发布](testing-release-status.md)。
