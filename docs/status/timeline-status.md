# 任务时间线状态

- 模块职责：把用户消息、智能体消息、计划、工具、命令和错误归一化为结构化多轮时间线。
- 当前状态：消息、计划、推理、命令、文件、MCP、动态工具、搜索、图片与子智能体活动均进入连续的结构化时间线；最近 200 个 Turn 直接挂载在单一原生滚动容器中。完成 Turn 的回复资源支持本地图片预览、Markdown 文件跳转和右键复制绝对路径；活动缩略图按需读取。
- 消息编辑：末回合结束后可替换单条用户输入，发送前使用 `thread/revert`，仅明确不支持分页时回退到 `thread/rollback`；回退失败保留草稿且不撤销文件修改。多用户输入回合不支持单条替换。
- 图片与文档：本地图片进入共享预览与批注窗口；本地 Markdown 无论是否位于项目内均进入 CS 文件面板，外部 URL 仍由浏览器打开。资源路径规范化不会放宽文件读取边界。
- 代码块：短 Markdown 代码块按内容收拢，保留语言标题和复制按钮；超长行限制在回复列内并在块内横向滚动。
- 最近变更：回复中的代码块采用内容自适应宽度，标题与正文间距收紧；长代码仍保留内部滚动。
- 当前接口：`agentSessionReducer`、`ConversationTimeline`、`ConversationTurn`、`TurnActivityGroup`、`TurnActivityItem`、`MarkdownContent`、`TurnFileChanges`、`TurnPlanView`。
- 已知问题：MCP/动态工具结构化结果仍以安全截断 JSON 展示；自动审批通知只依赖稳定摘要字段；尚未提供活动类型过滤、单个超长命令日志虚拟化和真实 Runtime 消息编辑端到端验收。
- 下一步：增加活动筛选和超长活动局部截断/虚拟化，补真实 Runtime 编辑链路验收。
