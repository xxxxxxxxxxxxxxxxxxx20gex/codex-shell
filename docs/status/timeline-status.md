# 任务时间线状态

- 模块职责：把用户消息、智能体消息、计划、工具、命令和错误归一化为结构化多轮时间线。
- 当前状态：消息、计划、推理、命令、文件、MCP、动态工具、搜索、图片与子智能体活动均已进入连续的结构化多轮时间线；长 Session 使用可变高度视口虚拟化，只挂载可见 Turn。
- 最近变更：同一回合的连续助手消息共享一个 Codex 头部；模型只在输入框的唯一选择入口显示，避免模型热切换后给不含模型元数据的历史 Turn 错误标注。用户消息气泡按内容自适应并受最大可读宽度约束；命令活动改为轻量可折叠行；原生 `fileChange` 项从中间活动流移到回答末尾，按路径去重并显示文件类型与增删行统计。智能跟随、新内容提示和用户消息导航继续保留。
- 当前接口：`agentSessionReducer`、`ConversationTimeline`、`ConversationTurn`、`TurnActivityItem`、`TurnFileChanges`、`TurnPlanView`。
- 已知问题：MCP/动态工具的结构化结果仍以安全截断 JSON 展示；尚未提供活动类型过滤。
- 下一步：增加活动筛选、单个超长命令日志虚拟化和文件变更详情跳转。
- 验证证据：reducer 测试覆盖命令/Plan delta、MCP progress、Item 生命周期、实时 Diff、历史文件变更重建和有界历史；静态及 happy-dom 测试覆盖单一助手头部、命令折叠、回答末尾文件汇总、回答复制/分叉、用户消息跳转、离底后不强制跟随和新内容提示。
