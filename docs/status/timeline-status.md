# 任务时间线状态

- 模块职责：把用户消息、智能体消息、计划、工具、命令和错误归一化为结构化多轮时间线。
- 当前状态：消息、计划、推理、命令、文件、MCP、动态工具、搜索、图片与子智能体活动均进入连续的结构化时间线；最近 200 个 Turn 直接挂载在单一原生滚动容器中。完成 Turn 的回复资源支持本地图片预览、Markdown 文件跳转和右键复制绝对路径；活动缩略图按需读取。回复中提到的本地资源通过 app-server `fs/getMetadata` 校验存在后才展示，避免把失败生成的路径误显示为附件。
- 消息编辑：末回合结束后可替换单条用户输入，发送前使用 `thread/revert` 返回的 metadata／cursor 获取保留历史，并消费对应通知避免重复加载。会话切换、Runtime reset 或新 Turn 后忽略迟到刷新。回退失败保留编辑草稿；回退已成功但历史刷新失败则清除旧编辑目标，保留草稿供重新发送。回退不撤销文件修改，多用户输入回合不支持单条替换。
- 图片与文档：本地图片进入共享预览与批注窗口；本地 Markdown 无论是否位于项目内均进入 CS 文件面板，外部 URL 仍由浏览器打开。资源路径规范化不会放宽文件读取边界。
- 代码块：Markdown 围栏代码铺满回复列，使用统一底色、20px 圆角、代码图标和语言标题；右上提供自动换行与复制。默认长行内部滚动，换行只影响显示，不改变复制文本。2026-10-08 四尺寸 Edge 探针及 6 项 Markdown 测试通过。
- 版面：回合内容列与 Composer 共用 `--column-content-width`（760px 上限）和 `--column-gutter`（32px，窄于 900px 时 16px），回合列与输入框左右对齐，代码块和用户气泡右缘对齐；回复保留 16px 标记缩进，窗口变窄时随视口收缩。命令输出、过程事件与终端交互使用 13px/20px（`--text-conversation-small`），消息操作 hover 改为中性高亮；时间线滚动按钮为 28px、16px／1.75 图标。2026-10-08，全量 427 项前端测试、工作台／代码块／终端四尺寸 Edge 探针通过；主时间线按滚动条外侧宽度定位，避免滚动条造成列边缘偏移。
- 最近变更：Core 终止错误与失败 Turn 完成事件相继到达时，仅清理同文案的顶部错误提示，失败原因仍保留在回合时间线；没有完成事件时顶部提示继续兜底。Core 活动项中的本地 `file://` 图片 URL 在元数据检查和预览前转换为文件路径；无效文件 URL 不作为可预览资源。适配 0.159.2 的托管图片 `fileId`，历史读取、编辑回填及再次发送保留原引用，不伪造成 URL 或本地路径。
- 当前接口：`agentSessionReducer`、`ConversationTimeline`、`ConversationTurn`、`TurnActivityGroup`、`TurnActivityItem`、`MarkdownContent`、`TurnFileChanges`、`TurnPlanView`。
